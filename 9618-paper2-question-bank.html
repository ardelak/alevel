9 · Algorithm Design and Problem-Solving

Decomposition, flowcharts, trace tables, searching, sorting and pseudocode.

Q1 [2 marks] Define abstraction and give a concrete example of its use in computer science.
Show answer & exam tip

Abstraction is the process of removing or hiding unnecessary detail to focus entirely on the essential features of a problem. Example: A tube map shows only stations and links, hiding real-world geographic distances and curves to make route planning easier.

EXAM TIP Give a specific, concrete example (like map routing or filtering out irrelevant database fields) to secure the second mark.
Q2 [2 marks] Explain decomposition and state two benefits of using it during software development.
Show answer & exam tip

Decomposition is breaking down a complex problem into smaller, manageable sub-problems. Benefits include: 1) Sub-problems are easier to solve and test independently. 2) Different modules can be developed in parallel by different team members.

EXAM TIP Never just say "it makes it faster." Use specific terms like "parallel development" or "independent testing."
Q3 [2 marks] State the purpose of a structure chart and identify two features it displays.
Show answer & exam tip

A structure chart models the modular top-down structure of a program. It displays the hierarchy of modules, the sequence of execution, and the data/control parameters passed between them.

EXAM TIP Remember that a structure chart shows modules and data flow, not the step-by-step logic (which is what a flowchart is for).
Q4 [2 marks] State the standard flowchart symbols used for a decision and for an input/output operation.
Show answer & exam tip

Decision: Diamond shape. Input/Output: Parallelogram shape.

EXAM TIP Process = Rectangle; Start/End (Terminal) = Rounded Rectangle.
Q5 [2 marks] Distinguish an algorithm from a computer program.
Show answer & exam tip

An algorithm is a logical, step-by-step sequence of instructions to solve a problem, independent of any specific programming language. A program is the concrete implementation of that algorithm written in a specific language's syntax (e.g., Python, Java) so a computer can execute it.

EXAM TIP Use the phrase "language independent" when describing algorithms.

Q8 [3 marks] Describe the procedural steps of a linear search, including its stopping conditions.
Show answer & exam tip

1) Start at the first item (index 1) in the array. 2) Sequentially compare each item with the target value. 3) Stop when the target is found (setting a flag to TRUE) OR when the end of the array is reached without a match.

EXAM TIP You must explicitly mention BOTH stopping conditions (found it, or reached the end) to get full marks.
Q9 [4 marks] State the necessary pre-condition for a binary search and describe how the algorithm works.
Show answer & exam tip

Pre-condition: The data must be sorted.
Method: Calculate the midpoint index. Compare the target to the midpoint item. If they match, stop. If the target is greater, discard the lower half. If the target is smaller, discard the upper half. Repeat this halving process on the remaining items until the target is found or no items remain (Low > High).

EXAM TIP "Sorted" is the most critical mark. Mention calculating the midpoint.
Q10 [1 mark] A sorted list contains 100 items. State the maximum number of comparisons a binary search needs to find an item or determine it is not present.
Show answer & exam tip

7 comparisons. (Because 2^7 = 128, which is the smallest power of 2 greater than or equal to 100).

EXAM TIP Just find the smallest integer 'n' where 2^n >= total items.
Q11 [3 marks] Describe how a bubble sort algorithm operates.
Show answer & exam tip

It iterates through the array, comparing adjacent items. If they are in the wrong order, it swaps them using a temporary variable. It repeats these passes through the list until a complete pass is made where no swaps occur (indicating the list is sorted).

EXAM TIP Mention the stopping condition explicitly: "A full pass with zero swaps".

Show answer & exam tip

EXAM TIP The largest value (8) will always "bubble" to the very end after the first pass.
Q13 [3 marks] Describe the mechanics of an insertion sort algorithm.
Show answer & exam tip

The array is conceptually divided into a sorted and an unsorted section. The algorithm takes the next item from the unsorted section and compares it against elements in the sorted section (moving right to left), shifting larger elements one space to the right, and then inserts the item into its correct sequential position.

EXAM TIP Emphasize "shifting elements" rather than swapping them. Think of sorting playing cards in your hand.
Q14 [2 marks] Explain one situation in which a linear search is preferable to a binary search.
Show answer & exam tip

When the dataset is unsorted, or when the array is very small. Sorting an unsorted array just to perform a single binary search takes significantly more computational time than simply doing a linear search.

EXAM TIP Binary search strictly requires sorted data. Mention the overhead time of sorting.

Types, arrays, records, files and abstract data types.

Q21 [3 marks] State the most suitable primitive data type for (a) a person's age, (b) a product price, (c) whether a seat is booked.
Show answer & exam tip

(a) INTEGER; (b) REAL; (c) BOOLEAN.

EXAM TIP Money values (with decimals) must be stored as REAL (or float/currency), never INTEGER.
Q22 [2 marks] Distinguish between the CHAR and STRING data types.
Show answer & exam tip

CHAR allocates memory for exactly one single character. STRING holds a sequence of characters of any length (including an empty string).

EXAM TIP "A" could theoretically be a String or a Char, depending entirely on its formal declaration.
Q23 [2 marks] Explain why a telephone number should be stored as a STRING rather than an INTEGER.
Show answer & exam tip

Telephone numbers often contain leading zeros which an INTEGER data type would automatically remove. Furthermore, phone numbers may include spaces or symbols (+, -) and are never used for mathematical calculations.

EXAM TIP Golden rule: If you do not perform arithmetic on it, declare it as a STRING (e.g., ID numbers, credit card numbers).
Q24 [2 marks] Define an array and state one advantage of using one in a program.
Show answer & exam tip

An array is a static data structure holding a fixed number of elements of the SAME data type under a single identifier, accessed via an index. Advantage: Prevents the need to declare hundreds of separate variables for related data.

EXAM TIP You must mention "same data type" and "accessed via index" for the full definition mark.

Q34 [3 marks] Describe a stack data structure and name its two primary operations.
Show answer & exam tip

A stack is a Last-In, First-Out (LIFO) abstract data structure managed by a TopPointer. PUSH adds an item to the top of the stack, and POP removes the item from the top of the stack.

EXAM TIP Mention the TopPointer and Underflow/Overflow checks.
Q35 [3 marks] Describe a queue data structure and name its two primary operations.
Show answer & exam tip

A queue is a First-In, First-Out (FIFO) abstract data structure managed by a FrontPointer and a RearPointer. ENQUEUE adds an item to the rear of the queue, and DEQUEUE removes an item from the front.

EXAM TIP Emphasize FIFO vs LIFO to distinguish a queue from a stack.
Q36 [3 marks] Explain the pointer manipulation required to insert a new node between existing nodes B and C in a linked list.
Show answer & exam tip

1) Allocate a new node from the Free List and populate its data. 2) Set the new node's pointer to point to node C (the current pointer stored in node B). 3) Change node B's pointer to point to the new node.

EXAM TIP Order is critical. If you overwrite B's pointer first, you completely lose the memory address of C!

Q41 [3 marks] Explain the fundamental difference in memory handling when passing parameters BYVAL compared to BYREF.
Show answer & exam tip

BYVAL (By Value): A local copy of the data argument is passed to the subroutine. Any modifications made inside the subroutine are discarded upon return and do not affect the original variable.
BYREF (By Reference): The memory address of the original variable is passed. The subroutine accesses and modifies the original memory location, so changes persist after the subroutine ends.

EXAM TIP Use the exact terminology: "Local copy" for BYVAL and "Memory address" for BYREF.

Q43 [2 marks] Distinguish a syntax error from a logic error.
Show answer & exam tip

Syntax Error: Occurs when the code violates the grammatical rules of the programming language (e.g., a missing parenthesis), preventing compilation.
Logic Error: Occurs when the program successfully compiles and runs, but produces an incorrect or unexpected output due to a flaw in the algorithm design (e.g., using a + instead of a -).

EXAM TIP Syntax errors are caught by the translator; logic errors are caught by testing (dry runs).

12 · Software Development

Life cycle, methodologies, testing and maintenance.

Q44 [3 marks] Describe the Waterfall lifecycle model and identify one major drawback.
Show answer & exam tip

The Waterfall model features distinct, sequential stages (Analysis, Design, Coding, Testing, Maintenance). Each stage must be fully completed and signed off before the next begins. Drawback: It is highly rigid—if client requirements change during the coding phase, it is extremely difficult and expensive to go back and alter the design, and no working prototypes are available until the very end.

EXAM TIP Contrast its rigidity with the flexibility of Iterative/RAD development.
Q45 [2 marks] Distinguish Alpha testing from Beta testing.
Show answer & exam tip

Alpha testing is conducted in-house by the company's own developers and dedicated QA testers before release. Beta testing is conducted by a selected group of real external users on their own hardware in real-world environments.

EXAM TIP Alpha is internal (simulated environment); Beta is external (live environment).
Q46 [2 marks] Distinguish Black-box testing from White-box testing.
Show answer & exam tip

Black-box: Tests the functionality and inputs against expected outputs without any knowledge of the internal code structure.
White-box: The tester has full access to the source code and designs test cases to verify all internal logical paths, conditions, and data flows.

EXAM TIP Black = can't see inside (testing specification). White = can see inside (testing structural logic).
Q47 [2 marks] State what a 'stub' is in the context of program testing.
Show answer & exam tip

A stub is a skeleton or dummy module that stands in for an unfinished subroutine. It usually returns a hardcoded, fixed value so that higher-level modules can be tested before the entire system is complete.

EXAM TIP Used extensively in Top-Down integration testing.
