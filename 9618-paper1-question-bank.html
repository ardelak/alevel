1 · Information Representation

Number systems, text, images, sound and compression.

Q1 [1 mark] Convert the 8-bit binary number 10110110 to denary.
Show answer & exam tip

182 (128+32+16+4+2).

EXAM TIPWrite the place values (128 64 32 16 8 4 2 1) above the bits first.
Q2 [1 mark] Convert 10110110 to hexadecimal.
Show answer & exam tip

B6 (1011 = B, 0110 = 6).

EXAM TIPSplit into 4-bit nibbles from the right.
Q3 [2 marks] Show −45 as an 8-bit two's complement binary number.
Show answer & exam tip

45 = 00101101; invert → 11010010; add 1 → 11010011.

EXAM TIPCheck by adding place values: −128+64+16+2+1 = −45.
Q4 [1 mark] State the range of denary values for 8-bit two's complement.
Show answer & exam tip

−128 to +127.

EXAM TIPThe negative side has one extra value because zero counts as positive.
Q5 [2 marks] Distinguish a kibibyte from a kilobyte.
Show answer & exam tip

1 kibibyte (KiB) = 1024 bytes (binary prefix); 1 kilobyte (kB) = 1000 bytes (denary prefix).

EXAM TIPQuote the actual numbers; the syllabus expects both prefix systems.
Q6 [3 marks] A bitmap is 800 × 600 pixels with 256 colours, uncompressed. Calculate the file size in KiB.
Show answer & exam tip

256 colours → 8 bits/pixel; 800×600×8 = 3 840 000 bits = 480 000 bytes = 468.75 KiB.

EXAM TIPFind colour depth first (2^n ≥ colours) and show each conversion step.
Q7 [2 marks] Explain the effect of increasing the resolution of a bitmap image.
Show answer & exam tip

More pixels, so more detail and higher quality; but the file size increases.

EXAM TIPGive both the benefit and the cost: 2 marks need 2 points.
Q8 [3 marks] Describe how analogue sound is stored digitally, including sampling rate and resolution.
Show answer & exam tip

Wave amplitude is measured at regular intervals (samples); each sample is stored as a binary value; higher rate/resolution gives more accurate sound but larger files.

EXAM TIPLink each setting to quality AND file size.
Q9 [1 mark] Give one advantage of Unicode over ASCII.
Show answer & exam tip

Represents far more characters, including many languages and symbols.

EXAM TIPDon't just say "uses more bits"; say why that matters.
Q10 [3 marks] Distinguish lossless from lossy compression and give an example of each.
Show answer & exam tip

Lossless: original can be rebuilt exactly (e.g. run-length encoding); lossy: data is permanently removed to reduce size (e.g. MP3, JPEG).

EXAM TIPName a method or format; RLE, MP3 and JPEG are safe examples.
Q11 [2 marks] Show the run-length encoding of WWWWBBBWW.
Show answer & exam tip

4W3B2W.

EXAM TIPWrite count-then-character pairs clearly. RLE works best with long runs.
Q12 [3 marks] Add 01101101 and 00110111 in binary and give the denary result. Does overflow occur in 8-bit unsigned?
Show answer & exam tip

10100100 = 164 (109 + 55); no overflow, as 164 ≤ 255.

EXAM TIPOverflow is a carry out of the most significant bit; add right to left.

2 · Communication and Internet Technologies

Networks, packet switching, addressing and the Internet.

Q13 [2 marks] Distinguish a LAN from a WAN.
Show answer & exam tip

LAN covers a small area (one building/site) and is usually owned by one organisation; WAN covers a large geographic area, often using leased/public links (e.g. the Internet).

EXAM TIPContrast on area AND ownership/infrastructure.
Q14 [3 marks] Compare client-server and peer-to-peer networks.
Show answer & exam tip

Client-server: central server holds data and services, easier backup/security, but costly and the server is a single point of failure; peer-to-peer: each computer shares its own resources, cheap and simple, but less secure and harder to manage.

EXAM TIPGive a feature of each plus a comparison, not just definitions.
Q15 [2 marks] Give one advantage and one disadvantage of a star topology.
Show answer & exam tip

Advantage: one cable failure affects only one device / easy to add devices; disadvantage: central switch failure stops the whole network / more cable needed.

EXAM TIPName the central device (switch) in the disadvantage.
Q16 [2 marks] State the role of a router.
Show answer & exam tip

Connects different networks; forwards packets towards their destination using IP addresses and a routing table.

EXAM TIP"Sends data" is too vague; mention IP addresses.
Q17 [2 marks] Explain why a switch is more efficient than a hub.
Show answer & exam tip

Switch uses a MAC address table to send data only to the intended device; hub broadcasts to all devices, causing collisions and wasted bandwidth.

EXAM TIPMAC address = switch; IP address = router.
Q18 [3 marks] Describe how data is sent using packet switching.
Show answer & exam tip

Data is split into packets; each has a header (addresses, packet number); packets may take different routes; they are reassembled in order at the destination.

EXAM TIPMention that routes can differ; it's the key idea.
Q19 [2 marks] State two items found in a packet header.
Show answer & exam tip

Destination IP address; source IP address; packet/sequence number; TTL; checksum (any two).

EXAM TIPThe payload (data) is NOT in the header.
Q20 [2 marks] Compare IPv4 and IPv6 addresses.
Show answer & exam tip

IPv4: 32-bit, dotted decimal, about 4.3 billion addresses; IPv6: 128-bit, hexadecimal, vastly larger address space.

EXAM TIPQuote the bit lengths for easy marks.
Q21 [2 marks] Explain the purpose of the Domain Name System (DNS).
Show answer & exam tip

Translates domain names (e.g. example.com) into IP addresses; DNS servers hold and look up the records.

EXAM TIPSay what goes in and what comes out.
Q22 [3 marks] Identify the protocol, domain name and file name in https://www.cie.org.uk/index.html.
Show answer & exam tip

Protocol: https; domain name: www.cie.org.uk; file: index.html.

EXAM TIPThe protocol ends before ://; the path/file follows the next /.
Q23 [2 marks] Distinguish public from private IP addresses.
Show answer & exam tip

Public: globally unique, assigned by the ISP, routable on the Internet; private: used inside a LAN, not routable on the Internet, can be reused by many networks.

EXAM TIPPrivate devices reach the Internet via the router (NAT).
Q24 [2 marks] Give one benefit and one drawback of wireless networking compared with wired.
Show answer & exam tip

Benefit: mobility / no cabling; drawback: slower or less reliable (interference) and easier to intercept.

EXAM TIPUse comparative words such as "faster" and "less secure".
Q25 [3 marks] Describe two advantages and one disadvantage of cloud storage.
Show answer & exam tip

Advantages: accessible from anywhere, scalable, provider handles backup/maintenance; disadvantage: needs Internet access, security/privacy concerns, ongoing cost.

EXAM TIPIf a scenario is given, relate your points to it.

3 · Hardware

Memory, storage, input/output devices and logic gates.

Q26 [2 marks] Distinguish between RAM and ROM.
Show answer & exam tip

RAM: volatile, read/write, holds running programs and data; ROM: non-volatile, read-only, holds the bootstrap/start-up instructions.

EXAM TIPUse the words volatile / non-volatile.
Q27 [3 marks] Compare SRAM and DRAM.
Show answer & exam tip

SRAM: faster, more expensive, no refresh needed, used for cache; DRAM: cheaper, needs constant refreshing, higher density, used as main memory.

EXAM TIPLink each type to where it is used.
Q28 [3 marks] Explain the purpose of virtual memory.
Show answer & exam tip

When RAM is full, part of secondary storage acts as extra memory; pages are swapped between RAM and disk; lets more programs run than fit in RAM, but is slower.

EXAM TIPMention swapping AND the speed drawback.
Q29 [2 marks] Describe how an SSD stores data.
Show answer & exam tip

Uses flash memory (NAND/NOR) made of transistors with floating gates; trapped electrons represent bits; no moving parts.

EXAM TIPContrast with the moving platter and head of a hard disk.
Q30 [3 marks] Give three differences between a magnetic hard disk and an SSD.
Show answer & exam tip

SSD: faster access, silent, more robust, lower power, no moving parts; HDD: cheaper per GB, larger capacities (any three).

EXAM TIP"Better" earns nothing; say faster, cheaper, etc.
Q31 [2 marks] Describe how data is read from an optical disc.
Show answer & exam tip

A laser is shone on the disc's spiral track; pits scatter the light and lands reflect it; reflections are detected and read as 1s and 0s.

EXAM TIPMention the laser and pits/lands.
Q32 [2 marks] Explain how a capacitive touchscreen detects a touch.
Show answer & exam tip

Screen layer stores charge; a finger changes the capacitance at that point; the processor calculates the position from the change.

EXAM TIPResistive screens work by pressure; don't mix them up.
Q33 [3 marks] Explain how an LCD screen produces a colour image.
Show answer & exam tip

Backlight shines through liquid crystals; crystals twist to control the light passing; red, green and blue filters on each pixel combine to make colours.

EXAM TIPMention the RGB filters; marks go for each stage.
Q34 [3 marks] Describe how a barcode reader reads a barcode.
Show answer & exam tip

Laser/light scans the barcode; black bars absorb and white bars reflect light; a photosensor converts reflections to a digital signal; the code is looked up in a database.

EXAM TIPFollow the order: light → reflection → sensor → signal.
Q35 [2 marks] Define an embedded system and give an example.
Show answer & exam tip

A computer system built into a larger device to perform a dedicated function; e.g. washing machine controller, car engine management.

EXAM TIPSay "dedicated function", not general purpose.
Q36 [2 marks] Complete the output column for X = NOT (A AND B), for A,B = 00, 01, 10, 11.
Show answer & exam tip

1, 1, 1, 0 (this is a NAND gate).

EXAM TIPWork out A AND B first, then invert.
Q37 [2 marks] An alarm X sounds when sensor A is on AND either B or C is on. Write the logic expression.
Show answer & exam tip

X = A AND (B OR C).

EXAM TIPUse brackets; without them the expression describes a different circuit.

4 · Processor Fundamentals

Registers, buses, fetch–decode–execute and assembly language.

Q38 [2 marks] State the purpose of the program counter (PC) and the memory address register (MAR).
Show answer & exam tip

PC holds the address of the next instruction to be fetched; MAR holds the address of the memory location being read from or written to.

EXAM TIPLearn all five: PC, MAR, MDR, CIR, ACC.
Q39 [4 marks] Describe the fetch stage of the fetch–decode–execute cycle using register names.
Show answer & exam tip

Address in PC copied to MAR; PC incremented; instruction fetched from that address into MDR; then copied from MDR to CIR.

EXAM TIPUse arrows (PC → MAR); clear register transfers earn the marks.
Q40 [2 marks] State the roles of the ALU and the control unit.
Show answer & exam tip

ALU performs arithmetic and logic operations; control unit decodes instructions and coordinates the other components with control signals.

EXAM TIPDon't say the CU "does calculations".
Q41 [3 marks] Describe the purpose of the address bus, data bus and control bus.
Show answer & exam tip

Address bus carries memory addresses (one way); data bus carries data and instructions (both ways); control bus carries control signals such as read/write.

EXAM TIPDirection matters: the address bus is unidirectional.
Q42 [3 marks] State three factors that affect processor performance.
Show answer & exam tip

Clock speed; number of cores; cache size; bus width (any three).

EXAM TIPIf asked "how", explain: higher clock speed = more cycles per second.
Q43 [3 marks] Describe how a processor handles an interrupt.
Show answer & exam tip

Checks for interrupts at the end of each cycle; if priority is high enough, saves register contents (e.g. PC) on a stack; runs the interrupt service routine, then restores registers and resumes.

EXAM TIPInterrupts are checked at the END of the cycle.
Q44 [2 marks] Give two advantages of using USB to connect peripherals.
Show answer & exam tip

Standard connector; plug and play / hot-swappable; can power devices; supports fast data transfer (any two).

EXAM TIPBe specific; "easy to use" alone is too vague.
Q45 [2 marks] Distinguish assembly language from machine code.
Show answer & exam tip

Machine code is binary run directly by the CPU; assembly uses mnemonics (e.g. ADD) and needs an assembler to translate it (one-to-one).

EXAM TIPAn assembler translates assembly; a compiler translates high-level code.
Q46 [3 marks] Explain the difference between direct and indirect addressing.
Show answer & exam tip

Direct: the operand is the contents of the address given; indirect: the address given holds the address of the operand, which must be followed to find the data.

EXAM TIPSketch a quick memory diagram to avoid confusion.
Q47 [2 marks] Address 300 holds 12. State the value stored at 301 after: LDM #8, ADD 300, STO 301.
Show answer & exam tip

20 (ACC = 8, then 8 + 12 = 20, stored at 301).

EXAM TIPLDM loads the number itself; ADD uses the contents of an address.
Q48 [3 marks] Explain how CMP 400 followed by JPE 20 works.
Show answer & exam tip

CMP compares ACC with the value at address 400 and sets a flag; JPE jumps to address 20 if they were equal, otherwise execution continues in sequence.

EXAM TIPThe comparison sets the status; the jump reads it.
Q49 [2 marks] ACC holds 10110110. State the result of AND #00001111 and its purpose.
Show answer & exam tip

00000110; masks the upper four bits (clears them) while keeping the lower four.

EXAM TIPAND clears bits, OR sets bits, XOR flips bits.
Q50 [2 marks] Perform a logical shift left of two places on 00110101 and state its effect.
Show answer & exam tip

11010100; equivalent to multiplying by 4 (53 × 4 = 212).

EXAM TIPLogical shifts fill vacated bits with 0s.

5 · System Software

Operating systems, utilities, translators and IDEs.

Q51 [2 marks] Describe two functions of an operating system.
Show answer & exam tip

Memory management; file management; process scheduling/multitasking; managing peripherals via drivers; providing a user interface; security (any two).

EXAM TIPName AND describe each function.
Q52 [3 marks] Explain how an operating system supports multitasking.
Show answer & exam tip

Allocates CPU time to each process in turn using scheduling; processes share the processor in time slices so they appear to run together; memory is allocated so processes don't interfere.

EXAM TIPMention time slices: one core runs one process at a time.
Q53 [3 marks] Describe paging in memory management.
Show answer & exam tip

Memory is divided into fixed-size blocks: pages (logical) and frames (physical); only needed pages are loaded into RAM; a page table maps pages to frames.

EXAM TIPPages are fixed-size; segments are variable-size.
Q54 [2 marks] State the purpose of a device driver.
Show answer & exam tip

Software that lets the OS communicate with and control a hardware device, translating OS commands into device-specific ones.

EXAM TIPIt is the link between the OS and hardware.
Q55 [3 marks] Name three utility programs and state the purpose of each.
Show answer & exam tip

Antivirus: detects/removes malware; disk defragmenter: rearranges file fragments to speed up access; backup software: copies data so it can be restored after loss (also compression, formatter).

EXAM TIPOne mark per name plus purpose pair.
Q56 [3 marks] Compare a compiler and an interpreter.
Show answer & exam tip

Compiler translates the whole program to an executable before running, so it runs faster and source needn't be distributed; interpreter translates and runs line by line, easier debugging but slower.

EXAM TIPMention error reporting: a compiler reports errors at the end, an interpreter stops at the error.
Q57 [1 mark] State the role of an assembler.
Show answer & exam tip

Translates assembly language into machine code.

EXAM TIPEasy mark; don't confuse it with a compiler.
Q58 [3 marks] State three features of an IDE that help with debugging.
Show answer & exam tip

Breakpoints; single-stepping; variable watch/report window; error diagnostics (any three).

EXAM TIPBe ready to explain what each does.
Q59 [2 marks] Give one advantage of using library routines in a program.
Show answer & exam tip

Pre-written and tested, so it saves development time and reduces errors; can be reused by many programs.

EXAM TIPLink to time AND reliability.
Q60 [2 marks] Distinguish between high-level and low-level languages.
Show answer & exam tip

High-level: close to human language, portable, needs translation; low-level: close to hardware, machine specific, gives direct control of hardware.

EXAM TIPUse "portable" and "machine-dependent".
Q61 [2 marks] Name two types of user interface and give one benefit of each.
Show answer & exam tip

GUI: icons/menus, easy for beginners; CLI: typed commands, fast and powerful for experts.

EXAM TIPTouch and voice interfaces are also acceptable.
Q62 [2 marks] Explain the purpose of the bootstrap program.
Show answer & exam tip

Stored in ROM; runs when the computer starts; loads the operating system from storage into RAM.

EXAM TIPLink it to "ROM is non-volatile".

6 · Security, Privacy and Data Integrity

Threats, protection, validation, verification and error detection.

Q63 [3 marks] Distinguish between data security, data privacy and data integrity.
Show answer & exam tip

Security: protecting data from unauthorised access or loss; privacy: right to control how personal data is collected and used; integrity: data is accurate, complete and consistent.

EXAM TIPOne mark each; define in your own words.
Q64 [2 marks] Distinguish a virus from a worm.
Show answer & exam tip

A virus attaches to a host file and needs user action to spread; a worm replicates itself over networks without a host or user action.

EXAM TIP"Self-replicating" belongs to the worm.
Q65 [3 marks] Distinguish phishing from pharming.
Show answer & exam tip

Phishing: fake emails trick users into giving personal details via fake links; pharming: malicious code redirects users from a genuine URL to a fake website.

EXAM TIPPharming redirects without the user clicking a bad link.
Q66 [2 marks] Explain how a firewall protects a network.
Show answer & exam tip

Monitors incoming and outgoing traffic; blocks traffic that doesn't meet security rules (ports, IP addresses).

EXAM TIPMention rules/criteria, not just "blocks hackers".
Q67 [4 marks] Compare symmetric and asymmetric encryption.
Show answer & exam tip

Symmetric: same key to encrypt and decrypt, fast, but the key must be shared securely; asymmetric: public key encrypts, private key decrypts, no secret sharing needed but slower.

EXAM TIPState the number of keys: one shared vs a pair.
Q68 [2 marks] Explain the purpose of SSL/TLS.
Show answer & exam tip

Provides secure, encrypted communication between client and server; verifies server identity using digital certificates (HTTPS padlock).

EXAM TIPLink it to HTTPS.
Q69 [3 marks] Distinguish validation from verification.
Show answer & exam tip

Validation checks data is sensible and meets rules (not that it is correct); verification checks data entered or copied matches the original.

EXAM TIPValid data can still be wrong, e.g. age 25 typed instead of 52.
Q70 [3 marks] Name and describe three validation checks.
Show answer & exam tip

Range check: within limits; length check: right number of characters; presence check: field not empty; also type, format, check digit (any three).

EXAM TIPGive an example value for each.
Q71 [2 marks] Describe one method of verification during data entry.
Show answer & exam tip

Double entry: data typed twice and compared; visual check: user reads the entered data against the source.

EXAM TIPVerification is about matching the source.
Q72 [1 mark] A 7-bit code 1101011 uses even parity. State the parity bit.
Show answer & exam tip

1 (there are five 1s, so a 1 makes the total even).

EXAM TIPCount the 1s; even parity makes the total number of 1s even.
Q73 [2 marks] Explain how a checksum detects transmission errors.
Show answer & exam tip

Calculated from the data before sending and sent with it; receiver recalculates and compares; a mismatch means an error.

EXAM TIPIt detects errors, it does not correct them.
Q74 [3 marks] Describe how ARQ works.
Show answer & exam tip

Receiver sends a positive acknowledgement if data is error-free, or negative if not; sender waits for a timeout; if no ACK arrives or a NAK arrives, the data is resent.

EXAM TIPMention the timeout; it is often forgotten.
Q75 [2 marks] Describe two measures to prevent unauthorised access to a computer system.
Show answer & exam tip

Strong passwords/two-factor authentication; biometric login; user access rights; firewall; encryption (any two).

EXAM TIPDescribe how each measure works.

7 · Ethics and Ownership

Professional conduct, licensing and the impact of computing.

Q76 [2 marks] State two principles found in a professional code of conduct (e.g. ACM/IEEE).
Show answer & exam tip

Act in the public interest; be honest and trustworthy; maintain competence; respect confidentiality and privacy; avoid harm (any two).

EXAM TIPGive the principles, not just the names of the bodies.
Q77 [2 marks] Explain what copyright protects in software.
Show answer & exam tip

Gives the creator legal control over copying, distributing and modifying their code; prevents unauthorised copying (piracy).

EXAM TIPSoftware is protected automatically.
Q78 [3 marks] Distinguish proprietary software, freeware and shareware.
Show answer & exam tip

Proprietary: bought, source code kept secret, licence limits use; freeware: free to use but copyright retained, no source code; shareware: free trial, pay to continue or get the full version.

EXAM TIPFreeware is not the same as open source.
Q79 [2 marks] Explain the term open source software.
Show answer & exam tip

Source code is freely available for anyone to view, modify and redistribute under a licence.

EXAM TIPSay "source code available".
Q80 [2 marks] Describe the philosophy of the Free Software Foundation.
Show answer & exam tip

Users should be free to run, study, modify, copy and share software; derived work must stay free (copyleft).

EXAM TIP"Free" means freedom, not zero price.
Q81 [2 marks] Explain why developers use software licence agreements.
Show answer & exam tip

They define how the software can be used, copied, modified or shared; protect the developer's rights and limit liability.

EXAM TIPState both rights and restrictions.
Q82 [2 marks] Give two ethical concerns about the use of artificial intelligence.
Show answer & exam tip

Bias in decisions from training data; job losses; privacy/surveillance; unclear accountability for errors (any two).

EXAM TIPBack each with a short reason.
Q83 [3 marks] Describe software piracy and two consequences.
Show answer & exam tip

Illegally copying or distributing software; consequences: fines/legal action, lost income for developers, malware risk in cracked software.

EXAM TIPInclude legal AND practical consequences.
Q84 [2 marks] Discuss one ethical issue of companies collecting personal data.
Show answer & exam tip

Data may be sold or misused without consent; breaches expose individuals; users may not know what is collected.

EXAM TIPTie your answer to consent or privacy.
Q85 [3 marks] A programmer finds a security flaw in her company's product just before release. Using a code of ethics, say what she should do.
Show answer & exam tip

Report it to management and press for it to be fixed or users told; public safety outranks deadlines; she must not conceal or exploit it.

EXAM TIPApply the principles to the scenario; don't just list them.
Q86 [3 marks] Discuss one social impact of increased automation.
Show answer & exam tip

Some jobs are lost to machines; new technology jobs are created; productivity and safety improve; retraining is needed.

EXAM TIPGive a positive and a negative for balance.
Q87 [2 marks] Give two reasons a company might release software as open source.
Show answer & exam tip

Community improves/fixes the code; builds user trust; wider adoption; lower development costs (any two).

EXAM TIPThink about benefits to the company, not the users.

8 · Databases

Relational design, normalisation and SQL.

Q88 [2 marks] Give two disadvantages of a file-based approach compared with a database.
Show answer & exam tip

Data redundancy and inconsistency; data dependence on programs; hard to share between users; poor security.

EXAM TIPUse the terms "redundancy" and "inconsistency".
Q89 [2 marks] Define the terms primary key and foreign key.
Show answer & exam tip

Primary key: attribute that uniquely identifies each record; foreign key: attribute that references the primary key of another table to link them.

EXAM TIPForeign keys create the relationships.
Q90 [3 marks] Define entity, attribute and tuple in a relational database.
Show answer & exam tip

Entity: object about which data is stored (a table); attribute: a field/column; tuple: one record/row.

EXAM TIPTuple = row, attribute = column.
Q91 [3 marks] State what is meant by third normal form (3NF).
Show answer & exam tip

Table is in 1NF and 2NF (no partial dependencies), and no non-key attribute depends on another non-key attribute (no transitive dependencies).

EXAM TIP"The key, the whole key and nothing but the key."
Q92 [2 marks] Students take many courses and each course has many students. Explain how to implement this.
Show answer & exam tip

Create a link table holding foreign keys for student and course; together they form a composite primary key.

EXAM TIPSplit a many-to-many into two one-to-many relationships.
Q93 [2 marks] Describe two functions of a DBMS.
Show answer & exam tip

Data dictionary maintenance; access rights/security; backup and recovery; concurrency control; query processing (any two).

EXAM TIPName AND describe each.
Q94 [2 marks] State two items stored in a data dictionary.
Show answer & exam tip

Field names; data types; sizes; validation rules; keys; relationships (any two).

EXAM TIPIt is data about data.
Q95 [3 marks] STUDENT(StudentID, Name, Year, Score): write SQL to list names of Year 12 students with Score above 60, highest score first.
Show answer & exam tip

SELECT Name FROM STUDENT WHERE Year = 12 AND Score > 60 ORDER BY Score DESC;

EXAM TIPClause order: SELECT, FROM, WHERE, ORDER BY.
Q96 [3 marks] Write SQL to show the average Score for each Year.
Show answer & exam tip

SELECT Year, AVG(Score) FROM STUDENT GROUP BY Year;

EXAM TIPNon-aggregated columns in SELECT must appear in GROUP BY.
Q97 [2 marks] Write SQL to add 5 to the Score of student 104.
Show answer & exam tip

UPDATE STUDENT SET Score = Score + 5 WHERE StudentID = 104;

EXAM TIPWithout WHERE every row is updated!
Q98 [2 marks] Write SQL to insert student 110, Amira, Year 12, Score 72.
Show answer & exam tip

INSERT INTO STUDENT (StudentID, Name, Year, Score) VALUES (110, 'Amira', 12, 72);

EXAM TIPText values need quotes; numbers don't.
Q99 [3 marks] STUDENT has foreign key ClubID referencing CLUB(ClubID, ClubName). Write SQL to show each student's Name and ClubName.
Show answer & exam tip

SELECT Name, ClubName FROM STUDENT INNER JOIN CLUB ON STUDENT.ClubID = CLUB.ClubID;

EXAM TIPQualify the keys with table names in the ON clause.
Q100 [3 marks] Write SQL to create table CLUB: ClubID integer primary key, ClubName text up to 30 characters.
Show answer & exam tip

CREATE TABLE CLUB (ClubID INTEGER PRIMARY KEY, ClubName VARCHAR(30));

EXAM TIPUse correct datatypes: INTEGER, VARCHAR(n), DATE, BOOLEAN.
